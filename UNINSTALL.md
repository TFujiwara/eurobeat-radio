# Uninstalling Eurobeat Radio

## Quick Uninstall

1. **Close** Forza Horizon 6
2. **Delete** `version.dll` from your FH6 installation folder
3. **Delete** the `fh6-radio` folder from your FH6 installation folder
4. **Done!** The mod is completely removed

## Restore Original Files (Optional)

If you want to fully restore the original game files:

1. Right-click **Forza Horizon 6** in Steam
2. **Properties** → **Local Files** → **Verify integrity of game files**
3. Steam will download any missing files

This restores the original radio configuration and any modified assets.

## Troubleshooting

**Files won't delete:**
- Close FH6 completely (check Task Manager)
- Restart Windows if needed
- Try again

**Dashboard still accessible after uninstall:**
- The bridge.exe process may still be running
- Restart your computer
- Or open Task Manager and kill any `bridge` or `fh6-radio` processes

**Want to keep the logo but remove the streaming:**
- Just delete `version.dll` and `fh6-radio`
- The logo will stay in place until you verify game files

---

**Need to reinstall?** Just run the installer again!

# Contributing to Eurobeat Radio

Thanks for your interest in contributing! This is a community-driven project.

## Issues & Feedback

- **Bug reports:** Describe the issue, game version, and reproduction steps
- **Feature requests:** Explain the use case and expected behavior
- **Questions:** Use the discussions section or GitHub issues

## Code Contributions

### Before Starting

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Keep changes focused and atomic

### C++ Code Standards

- Follow the existing code style (2-space indentation, camelCase for variables)
- Use `const` and references where appropriate
- Comment non-obvious logic
- Keep functions small and focused

### Building & Testing

1. Build locally: `.\scripts\build.ps1`
2. Test with your FH6 installation
3. Check `fh6-radio/bridge.log` for any errors or warnings

### JavaScript/Web UI

- Format with 2-space indentation
- Keep the dashboard simple and responsive
- Test in multiple browsers

### Commit Messages

```
Short description (under 70 chars)

Longer explanation if needed. Reference issue numbers:
Fixes #123
```

### Pull Requests

1. Describe what the PR does
2. Reference any related issues
3. Include testing notes
4. Ensure the build passes
